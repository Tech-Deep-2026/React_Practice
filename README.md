# Tailwind 
 - In Tailwind v3, running: by running 'npx tailwindcss init'
     --> would generate a tailwind.config.js file automatically, and you'd also need a postcss.config.js with tailwindcss and autoprefixer plugins.

 - In Tailwind v4 (released early 2025)
    - Instead of tailwind.config.js, you configure things directly in your CSS using @import and the new @theme directive.
    - The npx tailwindcss init command's behavior changed — it won't scaffold a config file the same way unless you explicitly ask for one.
